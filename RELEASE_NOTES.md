Hafþi beta 7 for Apple Silicon Macs (macOS 13 or later).

- Download `Hafthi-0.1.0-beta.7-macOS-arm64.zip`, unzip it, and drag `Hafþi.app` to Applications. No Xcode or build tools are needed.
- The Plugins overview explains that optional tools are installed separately with Homebrew.
- Each Fish, Starship, and tgpt settings page has its installation command and a link to the tool's GitHub repository.

This beta is ad hoc signed but not notarized with an Apple Developer ID. macOS may block it on first launch. After trying to open it, open System Settings → Privacy & Security → Open Anyway to approve this specific app.

Source code: https://github.com/pdahlbeck/hafthi-mac
