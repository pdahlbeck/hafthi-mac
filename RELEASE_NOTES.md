Hafþi beta 8 for Apple Silicon Macs (macOS 13 or later).

- Download `Hafthi-0.1.0-beta.8-macOS-arm64.zip`, unzip it, and drag `Hafþi.app` to Applications. No Xcode or build tools are needed.
- Each Plugins card now has an on/off switch matching its detailed settings.
- Fish can now be switched off. When disabled, new windows use the normal login shell instead of Hafþi automatically selecting Fish.

This beta is ad hoc signed but not notarized with an Apple Developer ID. macOS may block it on first launch. After trying to open it, open System Settings → Privacy & Security → Open Anyway to approve this specific app.

Source code: https://github.com/pdahlbeck/hafthi-mac
